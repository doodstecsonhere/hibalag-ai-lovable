# Hibalag AI

Hibalag AI is a mobile-first, multilingual digital guide for Silliman University’s 125th Founders Day and Hibalag Festival in August 2026.

## Highlights

- Conversational event and schedule discovery
- Bisaya, English, and Tagalog interaction
- Schedule-grounded responses backed by Supabase
- Interactive canvas for itineraries and categorized event lists
- Responsive PWA experience for desktop and mobile

## Technology

React, TypeScript, TanStack Start, Vite, Supabase, Tailwind CSS, and an AI SDK integration.

## Repository status

This public repository preserves the original Lovable implementation as a portfolio snapshot. It is no longer the primary development repository. The independent successor is maintained separately while the app is migrated away from Lovable.

**Original hosted build:** https://hibalag-ai.lovable.app

Platform-specific configuration is intentionally preserved to document the original architecture.
